### 2.3 Content Quality Standards

| Requirement | Standard |
|-------------|----------|
| Word count | Pillar: 3000+, Supporting: 2000+, Comparison: 2500+ |
| Keyword density | Primary: 1-1.5%, Secondary: 0.5-1%, LSI: natural |
| Structure | H1 → H2 → H3 hierarchy, Table of Contents, Jump links |
| Schema | Article/BlogPosting + FAQPage + HowTo + Product/SoftwareApplication |
| Internal links | 5-10 per article, contextual anchor text |
| External links | 2-3 authoritative sources per article |
| Images | 1 per 500 words, WebP, alt text with keywords |
| Meta | Title ≤60 chars, Description 150-160 chars, unique per page |
| CTA | Above fold + mid-article + end, clear "Start Free Trial" |
